## 📌 Overview

VTAB Sentinel Frontend is the web-based operational interface for the
VTAB Sentinel IoT monitoring platform.

It connects to the VTAB Sentinel backend API and provides operators with a
centralized interface to monitor:

- Device status
- Sensor telemetry
- Environmental readings
- Device health
- Alerts
- Operational events
- AI-generated insights
- System activity
- Monitoring statistics

The frontend is designed to provide a clear operational view of the entire
IoT monitoring pipeline.

---

## ✨ Key Features

### 📊 Operations Dashboard

Provides a centralized view of the Sentinel platform.

- Device health overview
- Telemetry summaries
- Active alerts
- Recent events
- System status
- AI analysis results

---

### 🌡️ Telemetry Monitoring

Monitor sensor measurements such as:

- Temperature
- Humidity
- Water leakage
- Door status
- Smoke/fire status

Telemetry data is received from the backend after being processed through
the MQTT ingestion pipeline.

---

### 🖥️ Device Monitoring

View device-level information including:

- Device ID
- Online/offline state
- RSSI
- Uptime
- Latest telemetry
- Device health

---

### 🚨 Alert & Event Monitoring

Provides visibility into operational events and alerts generated by the
Sentinel backend.

Operators can identify:

- Sensor anomalies
- Device issues
- Operational events
- System failures
- Recovery events

---

### 🤖 AI Insights

Displays analysis generated by the Sentinel AI service.

Examples include:

- Trend detection
- Sensor behavior analysis
- Forecast information
- AI-generated operational insights

---

### 🧪 Integrated Simulator

VTAB Sentinel includes a dedicated simulator environment for testing the
complete telemetry pipeline.

The simulator can generate ESP32-style telemetry and publish it through MQTT.

Simulator:

https://simulator.vtabsquare.com
