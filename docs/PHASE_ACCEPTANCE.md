# Phase acceptance checklist

## Phase 1

- Simulator-to-MQTT-to-database flow works; raw and clean readings persist.
- Master data, device state, HTTP APIs, login and role checks work.

## Phase 2

- Threshold breaches create alerts/incidents; operators can acknowledge/assign/resolve.
- Dashboard shows live data; AI endpoint returns prediction, anomaly, risk and explanation.

## Phase 3

- Configured adapters send/receive successfully; reports and audit records are accessible.
- Query/index review and backup/restore rehearsal are completed in the target environment.

## Phase 4

- Functional, integration, load, security and UAT suites pass.
- Monitoring, rollback, operational runbooks and final handover are approved.
